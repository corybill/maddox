# Lineage

The **scenario-testing** workspaces borrow the *ideas* behind [Maddox](../../README.md): fluent scenarios, keyed mocks, and explicit “given / when / then” flows—reimplemented for **Vitest**, **React Router 7**, and UI testing.

- There is **no** `import` from the Maddox `lib/` tree here.
- The **`maddox`** package does **not** depend on `@scenario-testing/*`.
- Naming is intentionally neutral on npm (`@scenario-testing/...`) while this repo keeps historical context.
